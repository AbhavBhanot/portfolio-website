# Profile Images

Place your profile photos here:

- `profile.jpg` - Main profile photo (800x800px square)
- `profile-hero.jpg` - Hero section photo (1200x800px, optional)
- `profile-about.jpg` - About page photo (optional)

**Recommended specs:**
- Format: JPG or PNG
- Main profile: 800x800px (square)
- Hero profile: 1200x800px (landscape)
- File size: Under 500KB
- Quality: Professional headshot with good lighting

**Tips:**
- Use a clean, professional background
- Good lighting is essential
- Dress professionally
- Smile naturally
- Consider hiring a professional photographer
- Use tools like remove.bg to remove backgrounds if needed
